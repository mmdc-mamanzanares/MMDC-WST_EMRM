# Employee Maintenance and Records Management System (EMRMS)

A lightweight web-based Employee Maintenance and Records Management System developed using HTML, CSS, and JavaScript. The application allows users to manage employee records, monitor workforce statistics, and maintain persistent data through browser local storage.

## Features

- Employee CRUD Operations (Create, Read, Update, Delete)
- Auto-Generated Employee IDs
- Employee Search and Filtering
- Dashboard Analytics and Counters
- Form Validation and Duplicate ID Checking
- Local Storage Persistence
- Responsive User Interface
- Employment Type and Status Tracking

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Browser Local Storage

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/mmdc-mamanzanares/MMDC-WST_EMRM.git
```

2. Navigate to the project directory:

```bash
cd emrms
```

3. Open `index.html` in your preferred web browser.

## Validation Rules

- Employee Name: Letters only
- Address: Letters, numbers, and `. , # ( ) -`
- Phone Number: 11 digits only
- Email Address: Valid email format
- Department: Letters only
- Position: Letters only
